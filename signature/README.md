# Signatures de mail

Images servies par GitHub Pages, à l'adresse
`https://amicial-communication.github.io/amicoop/signature/`.

| Fichier | Rôle | Taille réelle | Taille d'affichage |
|---|---|---|---|
| `logo-vert.png` | Logo formation | 320 × 116 | 160 × 58 |
| `logo-indigo.png` | Logo conseil | 320 × 116 | 160 × 58 |
| `baseline.png` | Par le domicile, pour le domicile | 464 × 56 | 232 × 28 |
| `photo-exemple-*.png` | Portrait d'exemple | 390 × 356 | 200 × 183 |

Les PNG font le double de leur taille d'affichage, pour rester nets sur
les écrans à forte densité. Les masters vectoriels des logos sont à côté,
en `.svg` : c'est d'eux qu'il faut repartir pour régénérer les PNG.

## Ajouter le portrait d'une personne

Déposer `photo-prenom-nom-vert.png` (ou `-indigo.png`) dans ce dossier,
au même format que les exemples : 390 × 356, fond transparent, photo
détourée à la forme d'un bras du symbole, cernée du trait de l'offre.
Puis remplacer le nom du fichier dans `formation.html` ou `conseil.html`.

## Installer la signature

Ouvrir `formation.html` ou `conseil.html` dans un navigateur, personnaliser,
sélectionner la signature, copier, coller dans Outlook
(Fichier > Options > Courrier > Signatures).
