# Charte de marque Ami'coop

Version publiée de la charte interactive : `index.html`, autonome, avec ses visuels dans `assets/`.

La page est en lecture seule ici — le mode édition n'existe que dans la version Claude,
qui reste la source. Pour mettre ce site à jour, régénérer l'export depuis cette source.

`<meta name="robots" content="noindex">` empêche l'indexation par les moteurs de recherche.
Retirer cette ligne dans `index.html` pour rendre la page référençable.
